## What I care about

```text
可靠性       不让异常穿透宿主进程，不把一次网络失败变成永久卡死
自动化       让调度器自己判断下一步，而不是要求用户频繁点按钮
可观测性     关键请求、状态迁移和失败原因都能被定位
工程质量     先验证边界，再交付设备；让修复可以复现、回滚和继续演进
```
